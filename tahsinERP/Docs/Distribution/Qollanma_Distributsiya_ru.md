# tahsinERP Дистрибуция — краткое руководство

Версия: пилот (1-й этап), 2026-10. Веб: раздел `/Distribution`. Бот: Telegram-бот вашей компании.

## Начало (для всех)

1. Получите у руководителя **код привязки** (страница **«Агенты и команды»**, для клиентов — карточка клиента).
2. Откройте ссылку или отправьте боту `/start КОД`. Бот напишет ваше имя и роль и покажет меню.
3. Язык: из профиля ERP (узбекский / русский) — бот на том же языке.
4. Если бот пишет «⛔ Лицензия системы неактивна» — сообщите администратору (ошибки с вашей стороны нет). «⚠️ Нет связи с ERP» — проверьте интернет и повторите через 1–2 минуты.

## Агент (бот + Mini App)

| Когда | Что делать |
|---|---|
| Утром | **▶️ Начать день** → **📍 Отправить геолокацию** |
| | **🗺 Маршрут** — клиенты на сегодня: ✅ посещён, ⏳ ожидает, 🚫 без заказа; виден долг |
| В магазине | Выберите клиента (или **🔎 Клиент** — поиск по названию) → **📍 Я на месте** → отправьте **трансляцию геопозиции**. Дальше 200 м — не принимается |
| Заказ | **🛒 Заказ** — откроется Mini App: поиск или категория, рекомендации (что клиент обычно берёт), **единица** (шт / коробка / поддон), количество → корзина → дата доставки, комментарий → **подпись** клиента → Отправить. Заказ попадает в офис со статусом «Новый» |
| Оплата | **💵 Оплата** → введите сумму (например `250000`) → способ: **наличные**, **карта** или **Click** (показываются способы, включённые руководителем). Наличные остаются **у вас** до сдачи в кассу; карта и Click сразу зачисляются на счёт компании. Повторное нажатие не создаст вторую оплату |
| Без заказа | **🚫 Без заказа** → причина (обязательно) |
| Фото | **📷 Фото** — полка / магазин |
| Вечером | **💵 Касса** → наличные на руках → **📤 Сдать в кассу** → передайте деньги кассиру. Кассир пересчитает и подтвердит |
| Конец дня | **🏁 Завершить день** → геолокация. Бот покажет итоги: визиты, заказы, собрано, наличные на руках |

Важно:
- Цена подставляется автоматически (тип цены клиента или спеццена). Скидка — только в пределах лимита вашей роли и не ниже минимальной цены.
- Заказ клиента с превышением лимита или просрочкой не подтверждается без разрешения руководителя — ему придёт уведомление в бот.
- Вы видите только своих клиентов.
- Будет добавлено: селфи в начале дня, новая торговая точка из бота, штрихкод камерой в Mini App.

## Экспедитор (1-й этап)

Рейсы и маршруты — на 2-м этапе. Сейчас: в боте **🔎 Клиент** → **📍 Я на месте** → при доставке **💵 Оплата** (наличные у вас) → вечером **📤 Сдать в кассу**. «Доставлено» отмечает оператор — сообщите ему.

## Кладовщик (веб)

| Шаг | Где |
|---|---|
| Подтверждённые заказы | **Заказы** → фильтр: статус «Подтверждён», ваш склад |
| Сборка | Карточка заказа → **Начать сборку** → **Лист сборки** (печать) |
| Отгрузка | **Отгрузить** → количество по строкам (всё или частично) → сохранить. Списание со склада по FIFO, долг клиенту. Печать **накладной** |
| Частично | Остаток отгрузите позже, или оператор **закроет остаток** (с причиной) |
| Остатки | **Остатки** — фактический / резерв / доступный; ниже минимума |
| Инвентаризация | **Инвентаризация** → склад и тип: **Начальная** (в начале пилота — приравнивает остаток к посчитанному) или **Контрольная** (в конце пилота — сравнение) → **Лист пересчёта** (Excel, без остатков системы) → заполните «Посчитано» (в базовой единице; нет товара — 0) → загрузите или введите на экране → **Провести**. Итог: число расхождений, недостача и излишек. Во время пересчёта не отгружайте с этого склада |
| Возврат | Документ возврата вводит оператор; приход на склад годного или брака |

Ошибочную отгрузку можно отменить в карточке заказа (если не доставлена и нет возврата). Будет добавлено: уведомление в бот о новом подтверждённом заказе.

## Кассир (веб)

| Шаг | Где |
|---|---|
| Оплата в офисе | **Оплаты** → **Оплата** → клиент, сумма, способ (наличные / карта / Click / Payme / Uzum / перечисление), счёт (касса или банк) |
| Наличные агентов | **Оплаты → Наличные агентов и касса** → сумма, сданная агентом → пересчитайте → введите **Пересчитано** → **Принять**. Разница (недостача/излишек) пишется в финансы отдельно, остаток кассы = реальные деньги. Если неверно — **Отклонить** |
| Ошибочная оплата | В карточке оплаты **Отменить** (с причиной). Сданные в кассу наличные агента не отменяются |

## Руководитель (бот + веб)

| Где | Что |
|---|---|
| Бот | Уведомление о крупном заказе и превышении лимита → **✅ Подтвердить** (разрешение руководителя) |
| Бот | Уведомление о сдаче в кассу; **📊 Итоги дня**; ежедневно в 20:00 — автоматические итоги |
| Веб: Долги | Долги клиентов по срокам (не наступил, 1–7, 8–30, 31–60, 60+), **акт сверки** (печать) |
| Веб: Заказы | По статусу, агенту, дате; себестоимость и прибыль — только с правом «видеть себестоимость» |
| Веб: Настройки | Лимит скидки (по ролям), минимальный и крупный заказ, радиус визита, склады |
| Веб: Импорт | Начальные данные (порядок указан на странице): сначала **предпросмотр**, затем **Импортировать** |
| Веб: Настройки → Оплаты агентов | Какими способами агент принимает оплату (наличные, карта, Click …) и на какой счёт идут карта/Click; касса для сдачи наличных агентов |
| Веб: Журнал ошибок | Новые проблемы (уведомление приходит и в бот) → уровень K1/K2/K3, статус, решение. Число открытых K1 — в заголовке |
| Будет добавлено | Панель руководителя и отчёты (разрезы продаж, план/факт, Excel) |

## Оператор (веб, кратко)

Заказы → **Подтвердить** (лимит, резерв, склад — автоматически). При блокировке по лимиту — разрешает руководитель. После доставки — **Доставлен**. Отмена — с причиной (только неотгруженные). Возврат — **Возвраты → Возврат** (по заказу или без, годный/брак, причина).

## Если ошибка или проблема (для всех)

- **В боте:** кнопка **⚠️ Проблема** (или `/xato`) → опишите, что делали и что произошло, с номером заказа/клиента. Можно отправить скриншот с подписью. Бот присвоит номер (P-001 …), руководитель получит уведомление.
- **В вебе:** Дистрибуция → **Журнал ошибок** → форма (где, номер документа, что произошло, ожидаемый результат).
- Если неверны деньги или остаток — сразу позвоните и руководителю (K1).
