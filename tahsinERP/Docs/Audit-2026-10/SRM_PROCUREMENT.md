## Cross-module notes

1. **Layout script stack** (_Layout.cshtml:1747-1786): jQuery is loaded twice (vendors.min.js, then `~/assets/js/jquery.min.js` at l.1779 *after* DataTables and select2 have registered on the first copy). This is why every SRM view contains `setTimeout` polling for `jQuery.fn.select2`. `datatable.js` (l.1775) auto-initializes `.zero-configuration` globally, which collides with the page inits (SRM-B21). Buttons, JSZip and pdfmake (more than 1 MB) are loaded from CDNs on **every page**. Fix this once in the Layout: one jQuery, page scripts in `@section scripts`, and heavy libraries only on pages that need them.
2. **Permission attribute:** replace the more than 60 inline `RoleHelper.IsXPermitted(...)` / `RedirectToAction("Index","ViewNotAuthorized")` blocks and the duplicate checks in views with `[ModulePermission("POrders", Access.Change)]`, and cache permissions per request (SRM-P11). It would also have prevented the missing checks in HSCode and on the AJAX actions (SRM-B10, B11).
3. **Lookup cache service** for Units, Currencies, Companies, HSCodes, Suppliers and Products, used by SRM, CRM (SContractController) and Warehouse.
4. **DocumentNumberService** is shared by P_ORDERS, P_CONTRACTS, P_INVOICES, P_REQUISITIONS, INCOMES, EXPENSES and S_*.
5. **VatMath** is shared by PContractVatHelper and SContractVatHelper (D11). Also decide whether stored amounts are net or gross (SRM-B25).
6. **Line-editor JS component** for all document-with-lines screens, including CRM and Warehouse (D13). This fixes the index-gap data loss (SRM-B05) everywhere at once.
7. **Hard-coded unit IDs** (`11` for m3 at PContractsController:316 and 708, `1` for dona, `5` for metre in services) should become named constants or be looked up from UNITS by code.
8. **Fire-and-forget logging and finance posting** (`LogHelper.LogToDatabase`, `FinancePostingService.PostPurchaseInvoice`) run synchronous DB calls inside async actions, opening their own contexts and calling SaveChanges several times. Consider an async variant that shares the caller's context and transaction.
