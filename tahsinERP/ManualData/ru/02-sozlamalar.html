1. О модуле

Раздел Настройки — фундамент системы. Здесь хранятся данные, которые вводятся один раз и затем используются всеми модулями: реквизиты предприятия, цвет системы и логотип, валюты и их курсы, единицы измерения, склады и ячейки внутри склада (DLOC). Если эти данные заполнены неверно, неверными окажутся и отчёты по закупкам, складу, продажам и финансам — поэтому их настраивают раньше всего остального.

Справочник (англ. master data) — редко меняющийся список, из которого значения выбираются в документах. Документы (приход, инвойс, счёт-фактура) создаются ежедневно и ссылаются на записи справочника. Например, в приходе название склада не набирается заново — оно выбирается из списка.

2. Глоссарий

Термины приведены с официальными названиями из МСФО (IFRS/IAS) и стандартов ISO — чтобы говорить на одном языке с внешним аудитором или инвестором.

Таблица 3. Глоссарий

Термин (в системе)

Международный термин / источник

Определение

Реквизиты предприятия

Company master data

Название, страна, город, DUNS, телефон, e-mail. Используются в шапке, логотипе и нижнем колонтитуле.

DUNS

D-U-N-S Number (Dun & Bradstreet)

Международный 9-значный идентификатор компании. Запрашивается во внешнеэкономической деятельности. Если номера нет — оставьте «-».

Цвет системы (цвет бренда)

Brand / accent colour; WCAG 2.1

Цвет меню, кнопок, ссылок и заголовков таблиц. Система сама обеспечивает читаемость текста (WCAG 2.1: контраст текста ≥ 4,5:1).

Функциональная валюта

Functional currency (IAS 21.8)

Валюта основной экономической среды компании. Для предприятия в Узбекистане — сум (UZS). В системе — «базовая валюта», её курс всегда 1.

Иностранная валюта

Foreign currency (IAS 21.8)

Любая валюта, кроме функциональной: USD, EUR, RUB, KRW…

Код валюты

ISO 4217 alphabetic code

Три заглавные латинские буквы: USD, EUR, RUB, UZS. По этому коду система запрашивает курс в ЦБ.

Курс валюты

Spot exchange rate (IAS 21.8)

Сколько сумов стоит 1 единица валюты на конкретную дату. Источник — Центральный банк Республики Узбекистан (ЦБ, cbu.uz) или ручной ввод.

Курс закрытия

Closing rate (IAS 21.8)

Спот-курс на последнюю дату отчётного периода. Применяется при переоценке монетарных статей.

Курсовая разница

Exchange difference (IAS 21.28)

Разница от пересчёта одной и той же суммы в валюте по разным курсам. Признаётся в прибылях или убытках.

Монетарная статья

Monetary item (IAS 21.16)

Деньги и активы/обязательства, получаемые или погашаемые фиксированной суммой денег: касса, банк, дебиторская и кредиторская задолженность.

Единица измерения

Unit of measure (UoM); UN/ECE Rec. 20

Единица учёта количества: шт, кг, м, коробка. У каждого товара есть основная единица.

Системный код

System code

Внутренняя метка программы (например, шт = PCS). Запись с системным кодом нельзя удалить, можно лишь переименовать.

Склад

Warehouse / storage location

Место хранения товарно-материальных запасов. Остатки ведутся по каждому складу отдельно.

Тип склада

Warehouse role

Сырьё (снабжение), производство или продажи. Автоматические процессы находят склад именно по типу.

DLOC (ячейка)

Bin / storage location

Конкретное место внутри склада: стеллаж, ряд, полка. Обозначается кодом (например, TK-A-01).

Партия (лот)

Lot / batch

Группа товара, поступившая одним приходом по одной цене. Себестоимость по FIFO ведётся по партиям.

FIFO

First-in, first-out (IAS 2.25)

Первым поступил — первым списан: себестоимость расхода берётся по самой старой партии (подробно — раздел 05 «Склад»).

Ответственный (MRP)

MRP controller

Сотрудник, отвечающий за запасы и потребность в материалах на складе.

Логическое удаление

Soft delete

Запись не стирается из базы, а помечается как удалённая и скрывается из списков. Старые документы не нарушаются.

Код ТН ВЭД (HS)

Harmonized System code (WCO)

Код товара по таможенной классификации (6–10 знаков). Нужен для импорта, экспорта и таможенных документов.

Вид дефекта

Nonconformity type (ISO 9001:2015, 8.7)

Справочник видов несоответствий, выявляемых при контроле качества.


3. Вход в раздел и устройство экранов

Группа Настройки находится в самом низу левого меню. Нажмите на неё ① — раскроется подменю:

Рис. 2. Левое меню: группа «Настройки»

•② Предприятие — реквизиты, цвет системы и логотип (раздел 4).

•③ Склады — список складов, тип, ответственный; отсюда же переход к ячейкам DLOC (разделы 7–8).

•④ Единицы измерения (раздел 6). Эта же страница доступна в меню Номенклатура → Единицы измерения.

•⑤ Коды ТН ВЭД — таможенные коды (виден только пользователям с правом доступа; раздел 9.2).

Другие пути: меню Склад → DLOC (ячейки); страница Курсы валют — по ссылке «курсы валют» на дашборде CRM или по адресу /CurrencyRates; Виды дефектов — в меню Производство → Качество.

3.1. Общее устройство страниц-списков

Все справочники устроены одинаково: сверху зелёная кнопка Добавить, над таблицей — выбор количества строк («Показать N») и поле Поиск (ищет по всем столбцам), в некоторых списках — кнопки экспорта Excel и PDF. Щелчок по заголовку столбца сортирует по нему. В каждой строке — зелёный карандаш (Изменить) и красная корзина (Удалить); они видны только пользователям с правом изменения.

Примечание: Пункты «Настроек» в меню видны всем, но при открытии страницы сервер проверяет права. Если прав нет, откроется страница «Нет доступа» — обратитесь к администратору (раздел 11.1).

4.2. Цвет системы (брендинг)

Цвет системы — это цвет меню, кнопок, ссылок, бейджей и заголовков таблиц. Есть 8 готовых цветов: Индиго (по умолчанию), Зелёный, Синий, Бирюзовый, Фиолетовый, Красный, Оранжевый, Графит. Можно задать и свой цвет HEX-кодом.

Рис. 4. Выбор цвета и живой предпросмотр

1.① Нажмите на кружок готового цвета (на рисунке — Синий). На выбранном кружке появится ✔.

2.② В поле HEX отобразится код цвета (#1F6FEB). Для своего цвета нажмите на палитру или введите код в формате #RRGGBB. Кнопка Цвет по умолчанию возвращает Индиго.

3.③ Блок образца показывает живой предпросмотр: меню, кнопки, бейджи, ссылку и поле в фокусе. Вся страница тоже перекрашивается — но только у вас и только на этой странице.

4.④ Если цвет подходит — Сохранить. Если нет — Отмена или обновите страницу: ничего не сохранится.

Как рассчитывается цвет

Вы выбираете один основной цвет; все остальные оттенки (наведение, светлый фон, вариант для тёмной темы) сервер рассчитывает автоматически. Для читаемости текста применяется требование WCAG 2.1 (ISO/IEC 40500):

Контраст = (L₁ + 0,05) / (L₂ + 0,05) ≥ 4,5

L₁, L₂ — относительная яркость (relative luminance) более светлого и более тёмного цвета. Цветной текст автоматически затемняется, пока контраст с фоном не станет не менее 4,5:1.

Надпись на цветной кнопке белая, если контраст с белым ≥ 3:1; иначе используется тёмная надпись. Поэтому даже при очень светлом цвете текст остаётся читаемым. Если выбран цвет по умолчанию (Индиго), в базу записывается «пусто» — при будущем обновлении стандартного цвета фирма автоматически перейдёт на него.

4.3. Логотип

•Формат — PNG или JPG, размер — до 200 КБ, квадратный (рекомендуется 256×256 пикселей).

•Логотип отображается в левом меню и на странице входа. Если он не загружен — показывается логотип tahsinERP.

•Удаление логотипа: если логотип загружен, рядом появляется флажок «Удалить логотип» — отметьте его и нажмите Сохранить.

•Браузер кэширует логотип до 10 минут; если новый не появился сразу, обновите страницу (Ctrl+F5).

5. Валюты и курсы валют

5.1. Справочник валют

На странице Настройки → Валюты — все валюты, с которыми работает фирма. В демонстрационной базе: USD, RUB, KRW, UZS и EUR.

Рис. 5. Список валют

•① Добавить валюту — форма новой валюты.

•② Таблица: название и краткое название (код ISO).

•③ Изменить, ④ Удалить (логическое удаление — старые документы сохраняются).

•⑤ Поиск — по названию или коду.

Добавление валюты

Рис. 6. Форма новой валюты (на примере EUR)

1.① Название валюты — полное название: «Евро».

2.② Краткое название — код ISO 4217, три заглавные латинские буквы: EUR. Это самое важное поле: по нему загружается курс ЦБ и оно отображается в документах.

3.③ Описание — обязательно, свободный текст (например, «Валюта Евросоюза»).

4.④ Сохранить. Новая валюта появится в выпадающих списках документов в течение 10 минут (списки кэшируются).

Внимание: Базовая (функциональная) валюта распознаётся по краткому названию: UZS (а также SUM, SO'M, SOM, СУМ, UZB). Не меняйте краткое название записи сума — иначе отчёты в сумах начнут искать курс и для сума, как для иностранной валюты.

Если краткое название — не ровно 3 латинские буквы (например, «$» или «Dollar»), курс из ЦБ автоматически не загрузится — останется только ручной ввод.


5.2. Страница «Курсы валют»

Курс — сколько сумов стоит 1 единица валюты на конкретную дату. Курсы хранятся в таблице CURRENCY_RATES: одно значение на валюту и дату плюс источник («CBU» или «Вручную»). Страница открывается по ссылке на дашборде CRM или по адресу /CurrencyRates.

Рис. 7. Страница «Курсы валют»

•① Фильтр: валюта (или «Все») и период. По умолчанию — последние 30 дней. Кнопка Показать обновляет таблицу.

•② Блок Ввод курса вручную (раздел 5.4).

•③ Блок Загрузка с ЦБ за период (раздел 5.3).

•④ Таблица курсов: дата, валюта, курс (в сумах, 4 знака после запятой), источник. Новые даты — сверху.

•⑤ Столбец Источник: «CBU» — загружено из Центрального банка автоматически, «Вручную» — введено или исправлено пользователем.

Сума (UZS) в списке валют нет — его курс всегда 1. Блоки ② и ③ видны только пользователям с правом изменения валют.

5.3. Загрузка курсов из ЦБ

Рис. 8. Блоки ручного ввода (1–4) и загрузки из ЦБ (5–7)

1.⑤ Выберите валюту (в примере — EUR).

2.⑥ Укажите период: дату начала и окончания. Период — не более 92 дней; будущие даты автоматически ограничиваются сегодняшним днём.

3.⑦ Нажмите Загрузить недостающие. Система проверяет каждый день периода и запрашивает в архиве cbu.uz только даты, по которым курса нет. Имеющиеся курсы (в том числе введённые вручную) не меняются.

4.Результат выводится зелёным сообщением: «Загружено курсов с ЦБ: 15.» Если по части дат ответа нет: «Загружено курсов с ЦБ: 9; нет ответа по датам: 3.» — обычно это обрыв связи или день, на который ЦБ курс не публиковал. Для таких дат документы берут ближайший предыдущий курс (раздел 5.5).

5.4. Ручной ввод и исправление курса

Когда нужно: нет интернета; валюты нет в ЦБ; договором установлен иной курс (например, курс конвертации банка); курс требуется исправить.

1.① Выберите валюту (USD).

2.② Укажите дату (27.10.2026).

3.③ Введите курс в сумах: 11850.25 (разделитель — точка). Курс должен быть положительным.

4.④ Сохранить. Если на эту дату курс уже есть, он заменяется, источник становится «Вручную». Каждый ввод записывается в журнал (кто, когда, какой курс).

Внимание: Ручной курс меняет сумовую оценку всех документов на эту дату — отчёты CRM, финансов и логистики при следующем открытии пересчитаются по новому курсу. Исправление курсов прошлых, закрытых периодов согласуйте с главным бухгалтером.


5.5. Как выбирается курс для документа

Когда отчёт или дашборд пересчитывает документ в иностранной валюте в сумы, курс ищется в таком порядке (CurrencyRateService.GetRate):

1.Если валюта — сум (UZS), курс = 1, пересчёт не нужен.

2.Если в таблице курсов есть курс ровно на дату документа — берётся он (из ЦБ или ручной).

3.Если нет и дата не в будущем — курс запрашивается на cbu.uz в реальном времени и при успехе сохраняется в таблицу с источником «CBU». Одна страница отчёта обращается к ЦБ не более 30 раз (чтобы страница не «зависла»).

4.Если ЦБ не ответил — берётся курс на ближайшую предыдущую дату из таблицы.

5.Если курс не найден вовсе — сумма документа не включается в итог в сумах, а над отчётом выводится предупреждение: «Не найден курс валюты для документов: N (KRW) — они не включены в итог в сумах. Введите курс на странице «Курсы валют».»

Пример: документ в USD от 21.10.2026. Курса USD на 21.10 в таблице нет, ЦБ тоже не ответил. Система возьмёт ближайший предыдущий — 12 044,72 сума на 20.10.2026.

5.6. Методика расчёта

Архив ЦБ иногда даёт курс за несколько единиц валюты (номинал). Система всегда приводит его к 1 единице:

Курс = CBU_Rate / CBU_Nominal

Например, при номинале 10 и курсе ЦБ 1 234,50 сума 1 единица = 123,45 сума.

Каждый документ в иностранной валюте пересчитывается в сумы по курсу на свою дату, затем суммы складываются:

Сумма_UZS = Сумма_вал × Курс(валюта, дата документа)

Итого_UZS = Σ Сумма_UZS (по документам, для которых курс найден)

7. Склады

Настройки → Склады (или Склад → Склады). Склад — место, по которому ведётся остаток. Каждый приход, расход и перемещение привязаны к конкретному складу; остатки и себестоимость FIFO также считаются по складу отдельно (IAS 2).

Рис. 12. Список складов

•① Добавить склад.

•② Название склада — щелчок открывает карточку склада.

•③ Тип — Сырьё (снабжение), Производство, Продажи или пусто (обычный склад).

•④ Столбец DLOC: левая кнопка — список ячеек склада, «+» — добавить ячейку (раздел 8).

7.2. Добавление склада

Рис. 13. Форма нового склада

1.① Название склада (обязательно) — понятное название, например «Склад аксессуаров (Бухара)».

2.② Описание — что хранится, адрес.

3.③ Тип склада — выберите по таблице в разделе 7.3. Тип определяется только этим полем, слова в названии склада не учитываются.

6.⑥ Сохранить. В пакетах с модулем производства для типа «Производство» появляется поле Цех — привяжите склад к цеху.

8. Ячейки склада (DLOC)

DLOC (detailed location) — конкретное место внутри склада: стеллаж, ряд, полка или зона. На складе с ячейками приходуемый товар размещается в конкретную ячейку, остаток партий ведётся по ячейкам, а расход по FIFO берёт партии из ячеек. Функция необязательная: небольшой склад может работать без DLOC.

Откройте через меню Склад → DLOC (ячейки) или кнопкой DLOC в списке складов. На рисунке — ячейки склада «Aksessuarlar ombori (Toshkent)».

•③ Таблица: склад, код ячейки, наименование.

•⑤ Смешанные партии / товары — можно ли хранить в одной ячейке несколько партий или разные товары. На узком экране остальные столбцы (Активна) раскрываются значком «+» в начале строки.

9.4. Поле выбора товара

В строках документов (приход, инвойс, заказ) поле выбора товара использует общий поиск:

•Введите часть артикула (PNo) или названия — подходящие товары выводятся по артикулу.

•За раз показывается 30 результатов; при прокрутке до конца списка подгружаются следующие 30.

•В некоторых документах показывается только сырьё или только готовая продукция (по признаку «сырьё» у товара или его категории).

•Удалённые товары не выводятся. При выборе товара его единица измерения подставляется в строку автоматически.

11.3. Часто задаваемые вопросы

•Курсы обновляются сами каждый день? Не по расписанию: если отчёту или дашборду нужен курс на дату, которого нет, он тут же загружается из ЦБ и сохраняется. Перед сдачей отчётности в конце месяца рекомендуется загрузить и проверить курсы вручную.

•А если по договору курс = ЦБ + 1%? Отчёты системы используют одну таблицу курсов. Если ввести договорной курс вручную, он заменит курс ЦБ на эту дату во всех документах — поэтому обычно оставляют курс ЦБ, а договорную разницу учитывают в самом документе.

•Что будет со старыми инвойсами, если удалить валюту? Ничего: удаление логическое, документы и суммы сохраняются со своей валютой; валюту просто нельзя будет выбрать в новых документах.

•Можно ли иметь несколько складов продаж? Да, их количество не ограничено. Для автоматических процессов по умолчанию берётся созданный первым (или совпадающий по цеху).

•Если переименовать склад, документы не «сломаются»? Нет, документы связаны со складом по ID; новое название отобразится везде.

•Можно поменять цвет только для себя? Нет, цвет системы общий для всей фирмы. Лично можно выбрать только светлую/тёмную тему (кнопка на верхней панели).

11.4. Советы

•Краткое название валюты всегда указывайте по ISO 4217 (USD, EUR, RUB, CNY) — тогда курсы будут загружаться автоматически.

•Перед закрытием месяца проверьте на странице курсов, что курс на последний день месяца есть по всем валютам.

•Задайте типы складов правильно до запуска фирмы — последующая смена типа меняет, с какого склада идут автоматические списания.

•Выберите единое правило кодов DLOC и печатайте их на этикетках; название — короткое, код — уникальный.

•Редактируйте справочники вместо удаления: удалённая запись видна в старых документах, но недоступна для новых.

•Все изменения (кто, когда, что) пишутся в журнал действий пользователей — при спорных ситуациях проверяйте журнал.
